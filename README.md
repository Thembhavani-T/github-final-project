# Simple Interest Calculator

A Bash script designed to calculate simple interest given principal, rate of interest, and time period in years.

## Input:
- **p**: Principal amount
- **t**: Time period in years
- **r**: Rate of interest per annum

## Output:
- **Simple Interest** = `(p * t * r) / 100`

## Usage:
```bash
./simple-interest.sh
